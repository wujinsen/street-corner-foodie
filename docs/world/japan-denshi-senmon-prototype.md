# 日本電子専門学校 · 街景原型（生成必读）

官方：[jec.ac.jp](https://www.jec.ac.jp/) · 维基：[日本電子専門学校](https://ja.wikipedia.org/wiki/%E6%97%A5%E6%9C%AC%E9%9B%BB%E5%AD%90%E5%B0%82%E9%96%80%E5%AD%A6%E6%A0%A1)

## 常见错误（勿画）

| 错误 | 正确 |
|------|------|
| 郊区单一校门 + 一片草坪 | **新宿大久保街区里多栋校舎分散** |
| 一所「大学城堡」玻璃楼 | **13 基ビル**（本館、2～12号館、7号館〈電子学園50〉等） |
| 海南/中国骑楼 | **东京密集路街、中高层混合建筑** |
| 只有一块「日本電子専門学校」招牌 | 多栋楼上各有 **本館 / ○号館 / 電子学園** 标识 |

## 真实原型

| 项 | 内容 |
|----|------|
| 法人 | 学校法人**電子学園** |
| 地址 | 〒169-8522 **東京都新宿区百人町1-25-4**（本館） |
| 形态 | **都市型キャンパス**：新宿·大久保周边 **13 栋**学园自有楼宇 |
| 交通 | **JR大久保站**南口步行约 2 分；西武新宿、新宿西口、新大久保、新宿站均在步行圈 |
| 本馆 | 职安通り一带**新建替え**大型楼宇，含中型ホール；AI / 信息处理 / 网安等 |
| 7号馆 | 标牌常带 **電子学園50**；CG·映像 / 游戏 / 动画 / 设计等 |
| 学科气质 | IT·游戏·CG·动画·电气（1951 年创立专门学校），学生通勤穿街于各馆之间 |

## 当地美食（街景须表现）

大久保·百人町学生街地面层饮食店（勿巨型海报风）：**ラーメン**、**牛丼**・カレー、**からあげ**、**たこ焼き**、**コンビニ**便当。详见 [japan-tokyo-street-prototypes.md](japan-tokyo-street-prototypes.md)。

## 街景 diorama 应表现

- **超宽**：同一条窄街可见 **2～4 栋**标号校馆（本館、7号館、10号館等），Q 版学生拎电脑包在楼间行走；远处可见大久保站方向街景。
- **夜景**：各馆窗户自习灯、招牌与便利店灯光，湿路面；仍为多栋楼宇，非单楼。
- **方图**：**本館**入口或楼间转角，日文校名 + 号馆指示牌。
