# 法国美食

## 概览

法国饮食以 **地区物产** 与 **技法**（酱汁、慢炖、 pastry）划分身份：巴黎 ** bistro / 咖啡馆**；里昂 **母酱与内脏**；普罗旺斯 **橄榄油与香草**；布列塔尼 **可丽饼与海鲜**；阿尔萨斯 **德式影响**；西南 **鸭油 confit、cassoulet**。面包店（**boulangerie**）与糕点店（**pâtisserie**）是日常街角。

**味型关键词**：beurre、herbes de Provence、vin rouge、crème、confiture、fromage、baguette croquant。

**资源状态（2026-05）**：海报 **3 品**（Macaron ✅ · **可颂** ✅ · 法棍 ✅ 2026-05-19 重绘）；zine / 街景 **部分**（巴黎 2 场景 night_wide ✅）。

## 巴黎一日动线（规划）

1. **晨**：**croissant** + café au lait（ comptoir 站立喝）。  
2. **午**：**steak frites** 或 **croque monsieur**。  
3. **下午**：**macaron** / **éclair**（ pâtisserie）。  
4. **夜**：**French onion soup** 或 **bouillabaisse**（若马赛线）；**crème brûlée** 收尾。

竖牌：**法国味道** / **巴黎味道** / **里昂味道** / **普罗旺斯味道**（**不**用街景区名竖牌，见 [food-poster-diorama.md](../style/food-poster-diorama.md)）。
