# 池袋 · 街景原型

> **仅用于 `Street View/` 街景出图。** 美食海报 / mini-zine **不** 因本页绑定池袋竖牌或分区时代（见 [food-poster-diorama.md](../style/food-poster-diorama.md) §与街景无关）。

## 要点

| 项 | 内容 |
|----|------|
| 区位 | 东京丰岛区 **池袋** 站周边（西口·东口·北口商圈） |
| 地标 | **サンシャインシティ** / **サンシャイン60** 高层、**池袋駅**、东口 **いけふくろう**（猫头鹰像集合点） |
| 气质 | 百货（西武·东武）、**オタロード** 动漫店、繁华换乘站 |
| 禁忌 | 中国骑楼、海南招牌、单一郊区校园 |

## 当地美食（街景须表现）

**餃子**、豚骨**ラーメン**、**たい焼き**、居酒屋・カラオケ（夜景）。详见 [japan-tokyo-street-prototypes.md](japan-tokyo-street-prototypes.md)。

## 招牌（日文示例）

池袋駅、東口、西口、サンシャインシティ、ラーメン、餃子、カラオケ、居酒屋、オタロード

## 三景别要点

| 景别 | 画面要点 |
|------|----------|
| day_wide | サンシャイン60 + 駅前饺子/拉面店 |
| night_wide | 东口霓虹、居酒屋·カラオケ |
| standard | 饺子盘或豚骨拉面碗，いけふくろう或 60 远景 |
