## 区位

**山梨县·富士河口湖町** — 富士五湖之一的 **河口湖**（河口湖駅周边）；街景 = **富士山远景 + 湖岸小镇饮食**（非纯登山空镜、非东京都市霓虹）。

| 项 | 说明 |
|----|------|
| 交通 | 新宿·东京站乘大巴/电车约 2h；河口湖駅为观光枢纽 |
| 季节 | 春樱、夏绿、秋红叶、冬雪顶；默认晴朗白天 wide |
| 气质 | 观光小镇、土特产店、湖滨食肆；夜景居酒屋·焼き鳥 |

## 地标

| 地标 | 说明 |
|------|------|
| **富士山** | 雪顶圆锥山体，画面背景居中或偏后 |
| **河口湖** | 湖面、游船、湖滨步道 |
| **红叶/樱花季意象** | 可按季节选樱花或红叶点缀（默认晴朗白天） |
| **忠灵塔方向** | 可选远景红色五重塔轮廓（勿抢主街） |

## 当地美食（生成须突出）

| 美食 | 要点 | 街景表现 |
|------|------|----------|
| **ほうとう** | 山梨名物，扁宽面片味噌汤煮南瓜蔬菜 | 招牌「ほうとう」「名物ほうとう」、大锅蒸汽 |
| **吉田うどん** | 富士吉田硬面乌冬 | 「吉田うどん」竖旗、碗面 |
| **信玄餅** | 黄豆粉麻糬 | 礼盒摊、信玄餅看板 |
| **湖鱼ます焼き** | 虹鳟/湖鱼盐烤 | 炭烤鱼摊、烟气 |
| **富士まんじゅう** | 富士造型馒头 | 温泉街特产店 |
| **わさび** | 富士山麓山葵 | 小摊山葵冰淇淋/芥末伴售（可选） |

**动线**：白天湖滨食肆 → 夜景居酒屋・焼き鳥；方图可特写 **ほうとう** 锅。

## 画面气质

- **day_wide**：河口湖岸道路 + 富士山全景 + ほうとう/うどん店，Q 版游客拍照吃面  
- **night_wide**：湖岸灯笼、居酒屋暖光，富士山剪影或低空云  
- **standard**：前景ほうとう锅/吉田うどん，背景富士一角  

## 招牌示例（日文）

河口湖、富士山、ほうとう、吉田うどん、信玄餅、ます焼き、湖の駅

## 禁忌

- 无饮食的空山空湖  
- 海报风巨型富士当唯一主体  
- 中国骑楼、海南热带棕榈、东京歌舞伎町霓虹主调  
- 中文「富士山」主招牌（可用少量中文观光字，**以日文为主**）

## 三景别要点

| 景别 | 画面要点 |
|------|----------|
| day_wide | 河口湖岸道路 + 富士山全景 + ほうとう/うどん店 + Q 版游客 |
