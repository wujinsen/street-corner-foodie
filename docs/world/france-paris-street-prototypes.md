## 埃菲尔铁塔 · `eiffel_tower`

### 区位

**巴黎七区·战神广场（Champ de Mars）** — **Tour Eiffel** 为画面主地标；前景仅留窄步道与小摊，**铁塔 + 战神广场绿带**为视觉终点。

| 项 | 说明 |
|----|------|
| **构图主语** | **埃菲尔铁塔**（含塔基绿草坪）占画面 **~50%**；美食/人物/奥斯曼立面为陪衬 |
| 视角 | **偏高俯视** 等距微缩（对齐 `haikou_wanlv_night_wide`）；三层景深 |
| 地标 | 夜景金灯 **Tour Eiffel** 全貌；可选塞纳河远景、特罗卡德罗轮廓 |
| 气质 | 铁塔金光 + 战神广场 + 小尺度 café 文化；**非**整排店面占满前景 |
| 语言 | 店招 **法文为主**（小摊即可） |

### 构图分层（night_wide · 必遵）

| 层 | 占比 | 内容 |
|----|------|------|
| **前景** | ~15% | 战神广场边缘窄步道、小 crêpe/café 摊、Q 版游客 |
| **中景（主）** | **~50%** | **Tour Eiffel** 全塔 + Champ de Mars 绿草坪、塔身金灯闪烁 |
| **远景** | ~20% | 塞纳河/巴黎天际线、薄雾、深蓝天 |

### 当地美食（生成须突出）

| 美食 | 街景表现 |
|------|----------|
| **Crêpe** 可丽饼 | 红色 crêpe stand、「Crêpes · Nutella」、摊前翻转铁盘 |
| **Baguette** 法棍 | **Boulangerie** 橱窗长棍、纸袋露出 |
| **Croissant** 可颂 | Café 露台小圆桌、可颂 + **café au lait** |
| **French onion soup** | bistro 暖窗「Soupe à l'oignon」（可选小招牌） |
| **Macaron / pâtisserie** | 甜点柜 pastel 色马卡龙盒（小摊即可） |
| **Steak frites** | bistro 黑板「Steak frites」（远景店招，非巨型主菜） |

### 三景别要点

| 景别 | 画面要点 |
|------|----------|
| day_wide | 战神广场绿草坪 + 铁塔全景 + crêpe/café 摊 + Q 版游客 |
| night_wide | **铁塔+战神广场占半幅** + 金灯 + 小 crêpe/café 摊 + chibi 游客（万绿园式景深） |
| day_standard | 前景 crêpe 或法棍摊，背景铁塔一角 |

### 招牌示例（法文）

Tour Eiffel、Crêpes、Boulangerie、Café、Bar à Vin、Soupe à l'oignon、Paris

### 禁忌

- 无饮食的空铁塔明信片  
- **整排 boulangerie/café 占满前景**（铁塔非主语）  
- 海报风巨型 croissant/macaron 占满画面  
- 中文主招牌（可极少量观光中文，**法文为主**）  
- 海南骑楼、东京霓虹主调

## 凯旋门 · `arc_de_triomphe`

### 区位

**巴黎八区·戴高乐广场（Place Charles de Gaulle / Place de l'Étoile）** — **Arc de Triomphe** 为画面主地标；**香榭丽舍大街（Champs-Élysées）** 自凯旋门向画面深处延伸。

| 项 | 说明 |
|----|------|
| **构图主语** | **凯旋门 + 香榭丽舍大道**合计占画面 **~50%**（对齐 `haikou_wanlv_night_wide` 景深） |
| 视角 | **偏高俯视** 等距微缩；三层：近岸步道 → 星形广场/凯旋门 → 香榭纵深 |
| 地标 | 暖金投光 **Arc de Triomphe**；星形环岛；**Champs-Élysées** 树阵 + 灯带向远方消失 |
| 美食 | crêpe、café、bistro、macaron — **仅河滨/步道小摊**，勿整排占满前景 |
| 语言 | 法文店招为主 |

### 构图分层（night_wide · 必遵）

| 层 | 占比 | 内容 |
|----|------|------|
| **前景** | ~15% | 香榭侧步道、小 crêpe/café 摊、Q 版行人 |
| **中景（主）** | **~50%** | **Arc de Triomphe** + 星形环岛 + **Champs-Élysées** 纵深大道（灯带透视） |
| **远景** | ~20% | 协和广场方向天际线、薄雾、深蓝天 |

### 当地美食（生成须突出）

| 美食 | 街景表现 |
|------|----------|
| **Crêpe** | 红色小摊、「Crêpes · Nutella」、铁盘蒸汽 |
| **Café / bistro** | 露台小桌、croissant + café au lait |
| **Macaron** | 小甜点柜 pastel 盒 |
| **Steak frites** | 远景 bistro 黑板，非巨型主菜 |

### 三景别要点

| 景别 | 画面要点 |
|------|----------|
| night_wide | **凯旋门+香榭占半幅** + 星形环岛 + 小摊/chibi 游客（万绿园式景深） |
| day_wide | 香榭方向远景 + 露天 café |
| day_standard | 前景 crêpe 或 macaron 摊，背景凯旋门一角 |

### 招牌示例（法文）

Arc de Triomphe、Champs-Élysées、Crêpes、Café、Bistro、Macarons、Paris

### 禁忌

- 无饮食的空明信片  
- **整排店面占满前景**（凯旋门/香榭非主语）  
- 海报风巨型 croissant/macaron 占满画面  
- 中文主招牌（**法文为主**）  
- 海南骑楼、东京霓虹主调
