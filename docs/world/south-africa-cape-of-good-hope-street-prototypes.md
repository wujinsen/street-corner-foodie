## 好望角 · `cape_of_good_hope`

### 区位

**西开普省·好望角（Cape of Good Hope / Cape Point）** — 桌山国家公园南端；大西洋岸著名岬角；**Cape Point Lighthouse**（白/黑条纹或新式灯塔）与 **Dias Cross** 为画面主地标。  
**非**厄加勒斯角（Agulhas 红白灯塔·最南端），**非**开普敦市区 Table Mountain 近景主调。

| 项 | 说明 |
|----|------|
| **构图主语** | **远景（海角·大西洋·星夜）占画面 ~50%**；人物与建筑**弱化**为边缘点缀 |
| 视角 | **远景俯视 / 高角度航拍式** 等距微缩（对齐 `tang_changan_night_wide`）；**拉远镜头**，建筑与 chibi **缩小、低对比** |
| 地标 | Cape Point **Lighthouse**、Dias Cross 纪念碑、风蚀 fynbos、玄武岩悬崖、Funicular 轨道（可微缩） |
| 气质 | 南大西洋风、星夜、灯塔光束扫海；Cape Point 旅游公路旁小栈 |
| 语言 | 店招 **英文 / 南非荷兰语** 为主（Vis & skyfies、Biltong、Two Oceans Café） |

### 构图分层（night_wide · 必遵 · 2026 修订）

| 层 | 占比 | 内容 |
|----|------|------|
| **远景（主）** | **~50%** | **大西洋深色海面 + Cape Point 岩石岬角全景 + 星夜深空 + 灯塔光束**；画面视觉重心 |
| **中景** | ~25% | 风蚀 fynbos 台地、Dias Cross 小标、 faint Table Mountain 远剪影 |
| **前景（弱化）** | ~15% | 极小的海岸公路弯、迷你 fish & chips / biltong 摊；**建筑低饱和、小尺度** |
| **人物** | 点缀 | **2～4 个极小 chibi**，仅作生活气息；**不可抢远景主调** |

> **弱化原则**：人物与建筑总面积 ≤ 画面 20%；招牌可读但非焦点；美食摊保留（规范要求）但缩至模型比例。

### 禁忌

- 无饮食的空海角明信片  
- 海报风巨型 braai 占满画面  
- 中文主招牌  
- 北半球棕榈/骑楼/东京霓虹主调  
- **Agulhas 红白条纹灯塔** 抢主景（本场景为 Cape Point 白黑灯塔）  
- Table Mountain 占画面 >30%（仅远景剪影）
