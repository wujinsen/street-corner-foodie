## 场景 · `north_pole`

### 区位

**地理北极点（Geographic North Pole · 90°N）** — 浮冰营地，非城市街景；巡航/探险自 **朗伊尔城 / 巴罗** 等出发，**入库国别 = arctic**（不归挪威/加拿大/美国）。

| 项 | 说明 |
|----|------|
| 主景 | 浮冰脊、极夜 **极光** 或极昼白蓝天空 — **远景占画面 ⅔** |
| 英雄 wildlife | **北极熊**（母熊+幼崽）站 **下 ⅓ 内** 中景浮冰 |
| 前景 | 橙色帐篷、`North Pole Camp · Hot Cocoa`、chibi 探险者（**≤8%** 贴底缘） |
| 语言 | 招牌 **英文** |

### 构图分层（`night_wide` / `day_wide`）

| 层 | 占比 | 内容 |
|----|------|------|
| **远景** | **~⅔（66%）** | 极光天空 + 无尽压冰脊 / 冰间水道 + 极远冰丘或破冰船剪影 |
| **中景** | **~⅓ 内** | 母熊 + 幼崽站浮冰；冰面倒映极光 |
| **前景** | **≤8%** | 橙色帐篷、`North Pole Camp · Hot Cocoa` 蒸汽、chibi 探险者围坐 |

### 当地美食

| 美食 | 表现 |
|------|------|
| Arctic Hot Chocolate | 蒸汽、保温杯、热饮站招牌 |
| Expedition Soup | 保温锅 |
| Pemmican / Rations | 补给箱 `Expedition Rations` |

### 命名

`arctic_north_pole_{day|night}_{wide|standard}.png`

### 禁忌

- 城市街道、热带植被  
- 无饮食空镜  
- 海报风巨型主菜  
- 北极熊攻击/血腥  
- 入库 `cn/` / `us/` 等城市目录（地理错误）
