## 通用

| 项 | 要求 |
|----|------|
| 画风 | 3D 等距微缩 + Q 版；~95% 画幅 |
| 气质 | 木质棚、铁皮烟筒、德州旗、烈日/暖光；**重烟熏**、酱碗在侧（德州常淡酱） |
| 招牌 | 英文 TEXAS BBQ、BRISKET、SMOKED MEATS |
| 禁忌 | 空停车场无饮食、NYC 石路霓虹、海南骑楼、巨型单品海报占满 |

## 食物画面要素

- 切片 **brisket**（粉红烟熏环 smoke ring）  
- **beef ribs**、**jalapeño cheddar sausage**  
- 白纸/tray、白面包 Texas toast、pickles、洋葱、coleslaw  
- 黑色烟熏炉、烟囱白烟
