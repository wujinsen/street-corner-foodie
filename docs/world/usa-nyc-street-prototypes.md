## 三景别通用要求

| 景别 | 内容 |
|------|------|
| **day_wide** | 餐车、店面、游客 Q 版；地标清晰 |
| **night_wide** | 霓虹、湿路面反光、橱窗暖光 |
| **day_standard** | 方图；**1～2 种街头食物特写** + 压缩地标 |

| 项 | 要求 |
|----|------|
| 画风 | 3D 等距微缩 + Q 版小人；画幅顶满 ~95% |
| 招牌 | **英文**为主（HOT DOGS、PIZZA、BAGELS、DELI） |
| 禁忌 | 海南骑楼、热带棕榈主景、日文主招牌、空街无饮食、巨型单品海报风 |

> NYC 约有 2 万+ 街头摊贩，热狗/椒盐卷饼为百年符号；时代广场亦常见 **halal cart**（黄饭+鸡肉/羊肉），画面可择一主调，避免摊种过杂。

## 1 · 时代广场 `times_square`

**区位**：**Times Square**（42nd–47th St，百老汇与 Seventh Ave）；剧院区入口、**TKTS** 红玻璃阶梯、巨型 LED 广告牌。

| 美食 | 街景表现 | 文化备注 |
|------|----------|----------|
| **热狗**（hot dog） | 黄色/蓝伞餐车、`HOT DOGS` 灯箱、芥末番茄酱 | 19 世纪德裔移民带来；深夜上班族快餐 |
| **椒盐卷饼**（pretzel） | 扭结碱水面包、粗盐、纸袋 | 地铁口与广场周边 impulse food |
| **披萨 slice** | `$1 PIZZA` / `PIZZA SLICE` 窗、折角吃 | 按片卖、站立快食 |
| **Halal cart**（可选） | 黄饭+鸡肉/沙拉、中东香料 | 广场高流量「正餐级」餐车 |

**地标**：TIMES SQUARE 霓虹、TKTS、百老汇剧院口、黄色出租车（远景）。

| 景别 | 画面要点 |
|------|----------|
| day_wide | 多餐车 + 披萨店 + 游客拍照 |
| night_wide | 霓虹屏 + 热狗灯 + 湿路面反光 |
| standard | 热狗 + pretzel 双持或餐车特写 |

**招牌示例**：TIMES SQUARE、NYC HOT DOGS、PRETZELS、PIZZA SLICE、BROADWAY

**已定稿**：`us_nyc_times_square_day_wide.png` · `us_nyc_times_square_night_wide.png` · `us_nyc_times_square_day_standard.png`

## 2 · 下城·金融区 `lower_manhattan`

**区位**：**Wall Street** 一带、**唐人街**（Chinatown）边缘、石铺老街；可远眺 **One World Trade**。

| 美食 | 街景表现 |
|------|----------|
| **百吉饼**（bagel） | `BAGELS` 店招、奶油芝士/烟熏三文鱼 |
| **Deli 三明治** | `DELI`、腌牛肉/火鸡厚切、黑麦面包 |
| **披萨 slice** | 金融区快餐窗 |
| **唐人街外卖** | `NOODLES`、`DUMPLINGS` 取餐窗、纸盒 |

**地标**：华尔街铜牛（Charging Bull）、石路、红砖楼、唐人街拱门（远景）。

| 景别 | 画面要点 |
|------|----------|
| day_wide | BAGEL 店 + DELI + 唐人街窗 |
| night_wide | deli 暖光、披萨店、外卖骑手 |
| standard | 百吉饼 + lox 或 cream cheese 特写 |

**已定稿**：`us_nyc_lower_manhattan_day_wide.png` · `us_nyc_lower_manhattan_night_wide.png` · `us_nyc_lower_manhattan_day_standard.png`

## 3 · 布鲁克林·DUMBO `brooklyn_dumbo`

**区位**：**DUMBO**（Down Under the Manhattan Bridge Overpass）；**曼哈顿大桥**钢架下、红砖仓库改文创、东河河岸。

| 美食 | 街景表现 |
|------|----------|
| **Smash burger** | 压扁肉饼、芝士、纸篮薯条；`BURGER` 霓虹 |
| **披萨 slice** | 大桥下披萨店 |
| **咖啡车** | specialty coffee cart |
| **冰淇淋** | 河岸散步（可选） |

**地标**：曼哈顿大桥支柱、红砖仓、河岸步道、布鲁克林天际线。

| 景别 | 画面要点 |
|------|----------|
| day_wide | 大桥下汉堡/披萨店 + 咖啡车 |
| night_wide | 桥灯、河岸餐座、burger joint 霓虹 |
| standard | smash burger + fries，大桥背景 |

**已定稿**：`us_nyc_brooklyn_dumbo_day_wide.png` · `us_nyc_brooklyn_dumbo_night_wide.png` · `us_nyc_brooklyn_dumbo_day_standard.png`

## 食客动线（曼哈顿）

1. **晨**：下城 **百吉饼 + lox** 或 deli  
2. **午**：唐人街外卖 / 金融区 pizza slice  
3. **傍晚**：DUMBO **smash burger** 配河岸散步  
4. **夜**：时代广场 **热狗 + pretzel**（观剧前后）

---

## 通用禁忌

- 巨型汉堡/披萨海报占满画面（应以街巷+店窗为主）  
- 混用海南骑楼、东京歌舞伎町主霓虹  
- 空街无餐车无店
