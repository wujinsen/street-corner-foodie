# 德国美食

## 概览

德国饮食以 **地区物产** 与 **啤酒/面包/香肠** 为国民符号：巴伐利亚 **Weißwurst、Brezel、Biergarten**；莱茵兰 **Kölsch、Bratwurst、Currywurst**；柏林 **Currywurst、Döner**；施瓦本 **Spätzle、Maultaschen**；北德 **Fischbrötchen**。面包店（**Bäckerei**）与 **Wurstimbiss** 是日常街角。

**味型关键词**：Senf、Sauerkraut、Bier、Brezel、Wurst、Kartoffel、Schnitzel。
