# 南非美食

## 概览

南非饮食融合 **荷兰殖民**、**马来奴隶传统（Cape Malay）**、**英国** 与 **非洲本土** 技法；国民社交中心是 **braai**（露天炭烤）。沿海 **炸鱼薯条、新鲜 linefish**；内陆 **biltong、droëwors**；开普区 **bobotie、koeksisters**；德班 **bunny chow**。

**味型关键词**：braai smoke、biltong、 peri-peri、 chakalaka、 rooibos、 malva pudding。
