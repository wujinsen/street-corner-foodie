# 日本美食

## 概览

日本饮食强调 **旬（季节）**、**出汁与鲜味**、**刀工与摆盘**，米食（饭、寿司、丼）与面类（拉面、乌冬、荞麦）并重。地方差异大：关东汤底偏酱油清亮，关西偏昆布鱼介；北海道海鲜、九州豚骨与明太子、山梨乡土锅物、**冲绳琉球与美式融合**等各具标识。本项目街景已覆盖 **东京 9 区 + 富士河口湖**（见下）；冲绳美食见 **[§冲绳特设美食](#冲绳特设美食)**，海报 / zine 按代表菜逐步入库。

**味型关键词**：うま味、清淡、酸甜醋、醤油味、豚骨浓汤、炸物酥脆、抹茶甘味、**泡盛·黑糖·岛盐**、苦瓜杂炒、海葡萄爆珠。

## 东京一日动线（食客向）

1. **晨**：筑地·丰洲 **海鮮丼** / 玉子焼き → 浅草 **人形焼**、天ぷら。  
2. **午**：上野阿美横 **弁当**、零食 → 秋叶原 **カレー** / 拉面。  
3. **傍晚**：原宿 **クレープ** → 涩谷 **肉巻き** 或拉面。  
4. **夜**：新宿 **居酒屋·焼き鳥** / 焼肉 → 池袋 **豚骨拉面·餃子**；大久保 **牛丼·からあげ**（电子专门学校街区）。

> 街景分区与画面美食 **仅** 见下节「街景微缩」— **不** 反向约束海报 / zine。

## 饮食小贴士

1. **拉面**：汤先尝再拌；豚骨系偏腻可少喝底；替玉仅面不加汤。  
2. **寿司**：握り宜一口；姜是清口用非配鱼；Wasabi 已夹在饭鱼间勿再猛蘸。  
3. **丼饭**：牛丼快餐可要求饭量/汁量；温泉蛋另加常见。  
4. **居酒屋**：焼き鳥按串点；先点啤酒+小碟再主菜；お通し（入座小菜）可能收费。  
5. **浅草**：仲見世边走边吃注意垃圾规则；人形焼趁热。  
6. **富士**：ほうとう一锅出，宜共享；河口湖鱼料理选当季。  
7. **海报 / zine 生成**：人物数、碗数见 [food-poster-ingredients.md](../style/food-poster-ingredients.md) §日本；竖牌 **日本味道** / **东京味道** / **江户味道** / **冲绳味道**（**不**读街景分区表，见 [food-poster-diorama.md §与街景无关](../style/food-poster-diorama.md)）。  
8. **冲绳**：见 [§冲绳特设美食](#冲绳特设美食)；面类优先 **沖縄そば**（非本岛そば）。

- **面**：小麦粉 **100%**，黄色 **ちぢれ麺** 或平麺，口感弹牙。
