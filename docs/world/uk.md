# 英国美食

## 概览

英国饮食以 **家常炖烤**、**酒吧（pub）**、**下午茶** 与 **街头炸物** 为国民记忆；英格兰、苏格兰、威尔士、北爱尔兰各有标识菜。战后移民带来 **印度咖喱**、**中东 kebab** 等，形成「英式印度菜」（如 chicken tikka masala）等当代符号。味型偏 **咸鲜、奶脂、麦芽醋、芥末**；甜点常 **黄油、焦糖、莓果**。

**味型关键词**：roast、gravy、malt vinegar、black pudding、clotted cream、smoked fish、whisky、ale。

## 伦敦食客动线（规划）

1. **晨**：East End **pie and mash** 或 **full English**。  
2. **午**：**fish and chips**（Paper-wrapped）+ mushy peas。  
3. **下午**：**afternoon tea**（Mayfair / hotel）或 **scone**。  
4. **夜**：**pub Sunday roast**（若周日）或 **bangers and mash** + ale。

> 街景与海报 **不绑定** 单一街区；竖牌用 **英国味道** / **伦敦味道** / **苏格兰味道** 等广域风味（见 [food-poster-diorama.md §与街景无关](../style/food-poster-diorama.md)）。
