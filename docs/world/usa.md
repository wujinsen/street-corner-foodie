# 美国美食

## 概览

美国饮食是 **全球移民与地方物产** 叠加的结果，没有单一「国菜」，更常见的是 **按州/海岸带** 识别的符号食物：南部烟熏烧烤、东北部海鲜与蛤蜊汤、中西部牛排与玉米、西南部墨西哥裔料理、西海岸亚洲融合与健康轻食等。快餐文化（汉堡、炸鸡、披萨连锁）影响全球，但精品餐饮与农夫市集、BBQ pit、food truck 同样代表当代美国味。

**味型关键词**：烟熏、芝士、酸甜烧烤酱、油炸酥脆、大份量、海鲜鲜甜、辛香（Cajun / 墨西哥椒）。

本项目 **纽约 + 洛杉矶 + 德州 BBQ 街景各 9 张**已入库（`us/nyc/`、`us/la/`、`us/tx/`）；海报 / zine 部分已扩。下文列出代表菜与建议 slug。

## 纽约一日动线（食客向）

1. **晨**：下城 **百吉饼 + lox** 或 deli 三明治。  
2. **午**：唐人街外卖 / 披萨 slice（金融区或时代广场）。  
3. **傍晚**：布鲁克林 DUMBO **smash burger** 或水岸披萨。  
4. **夜**：时代广场 **热狗 + pretzel**；或百老汇口餐车。

---

## 饮食小贴士

1. **小费**：餐厅 sit-down 通常 18–20%；快餐、餐车可不给或少量。  
2. **披萨**：按片卖宜折角吃；整 pie 常 8 片大号。  
3. **百吉饼**：先烤后夹；lox 款冷食，cream cheese 款最常见。  
4. **BBQ**：酱汁地区差异大，德州重烟熏少酱，KC 偏甜番茄酱。  
5. **蛤蜊汤**：白汤浓腻配酸面包挖碗；红汤番茄系在波士顿常见。  
6. **海报 / zine**：人物数、配料碗见 [food-poster-ingredients.md](../style/food-poster-ingredients.md) §美国；竖牌 **纽约味道** / **美国味道**。
