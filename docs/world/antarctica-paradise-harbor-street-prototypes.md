## 天堂湾 · `paradise_harbor`

### 区位

**南极半岛·天堂湾（Paradise Harbor / Paradise Bay）** — 南极经典巡航登陆点；冰川直插海湾、浮冰、巴布亚企鹅（Gentoo）群落；近 **González Videla** 智利站（可微缩）。  
**非**新西兰 Milford Sound；**非**新西兰领土；巡航可从 NZ 出发但**入库国别 = 南极**。

| 项 | 说明 |
|----|------|
| **构图主语** | **远景南极全景占 ~60–70%** — 冰川壁、浮冰海湾、雪山横贯地平线；**气势磅礴**、镜头极远 |
| 视角 | **超远景俯视 / 极远航拍** 等距微缩；前景营地 ≤8%；**无人物** |
| 地标 | 冰川 front、Paradise Harbor 静水、冰山、雪原、远峰；可选极小科考模块 |
| 气质 | 极夜 / **黄昏金粉暮色**（参考海口湾 sunset）、探险暖灯 |
| 语言 | 招牌 **英文**（Expedition Café、Hot Chocolate、Polar Soup） |

### 构图分层（night_wide_no_char · 必遵）

| 层 | 占比 | 内容 |

## v2 · 镜海冰川 + 浮冰企鹅（`day_wide` ✅ · `night_wide` ✅）

> **定位**：南极半岛最著名的巡游地 — 海面平静如镜，巨大蓝色冰川倒映水中；金图企鹅（Gentoo）、座头鲸、海豹为近景/中景主角。  
> 与 v1 `_no_char` 超远景并存；新稿建议文件名 **`…_day_wide.png` / `…_night_wide.png`**（无 `_no_char`），或试绘后缀 `…_mirror_redraw.png`。

### 核心视觉（必达）

| 元素 | 要求 |
|------|------|
| **镜海** | 海湾水面 **极静**，清晰倒映冰川壁与天空；day 为蓝白对称，night 为星点/暖光倒影 |
| **蓝冰川** | 横贯远景的 **巨大蓝色冰壁**（ice cliff / glacier front），**占画面约 ⅔**（含天空与冰壁） |
| **金图企鹅 Gentoo** | **3～6 只** 站在 **中景浮冰块** 上；白腹黑背、橘喙，姿态各异（站立、理羽、望向水面）— **不是**极小背景点 |
| **座头鲸** | 可选 **1 处** 远中景：尾鳍出水或喷气，不抢冰川主景 |
| **海豹** | 可选 **1 只** 在邻近浮冰打盹，尺度小于企鹅群 |
| **巡游感** | 远景极小：探险邮轮剪影或橙色 **Zodiac** 橡皮艇，暗示登陆巡游 |

### 构图分层（v2 · day_wide / night_wide）

| 层 | 占比 | 内容 |
|----|------|------|
| **远景** | **~⅔（66%）** | 蓝色冰川壁 + 雪山 + 极地天空 + 邮轮/Zodiac 微缩 — **占画面主体** |
| **中景 + 镜海** | **~⅓ 内** | **浮冰群 + 3～4 只 Gentoo 企鹅**；镜海倒映冰与鸟 |
| **前景** | **≤8%** | 探险热饮站 / `Expedition Café` 暖光、保温杯蒸汽（贴底缘） |

### 白天 `day_wide` 要点

- **光**：高纬度清澈日光，冰川呈 **钴蓝 + 白**，阴影偏青灰  
- **水面**：如镜子；冰川、浮冰、企鹅 **上下对称倒影**（可略涟漪打破完美对称以免 AI 呆板）  
- **企鹅**：占中景浮冰 **清晰可辨**，与迷你沙盘比例协调（手办感 wildlife，非写实纪录片特写）  
- **色温**：冷蓝主调 + 前景热饮站 **小面积暖橙** 对比  

### 夜景 `night_wide` 要点

- **光**：**明亮极夜**（非全黑）；冰川被月光/营地灯勾边，星空可见  
- **镜海**：星点与冰川暖光 **倒映水面**；企鹅轮廓仍可读  
- **暖点**：前景 `Polar Hot Chocolate` 小站（参考海口夜景 wide 的亮度与密度）  
- **可选**：南极暮光紫粉天际（比 Arctic 极光更 subtle）
