## 三景别通用要求

| 景别 | 内容 |
|------|------|
| **day_wide** | 横向全景；地标 + 多摊多店；Q 版行人排队、端碗；日光清透或都市阴天 |
| **night_wide** | 霓虹/暖帘/灯笼；居酒屋烟、拉面店灯牌；湿路面反光（都市夜景） |
| **day_standard** | 方图；**1～2 种当地美食特写**（碗/串/握寿司），背景压缩地标 |

| 项 | 要求 |
|----|------|
| 画风 | 3D 等距微缩 + Q 版小人；画幅顶满 ~95% |
| 招牌 | **日文**为主（ラーメン、寿司、居酒屋、焼き鳥） |
| 饮食 | 须有摊/店/碗碟/食客；**禁**空街、巨型单品海报风 |
| 禁忌 | 中国骑楼、海南热带棕榈主景、中文小吃主招牌 |

## 1 · 新宿 `shinjuku`

**区位**：JR **新宿站**西口外；**思い出横丁**（おもいで横丁，约 80 家小店、炭火焼き鳥）与 **歌舞伎町**霓虹带；都厅双塔可作远景。

| 美食 | 街景表现 | 参考 |
|------|----------|------|
| **焼き鳥** | 横丁红灯笼、炭烟、串烧柜台、啤酒杯 | 思い出横丁名物 |
| **ラーメン** | 一風堂/家系等楼下拉面灯牌 | 站周边 24h 面店 |
| **牛丼** | 吉野家·松屋类竖牌、大碗牛肉饭 | 快餐即食 |
| **居酒屋** | 暖帘「居酒屋」、ビール、小碟 | 夜景 wide 重点 |
| **焼肉 / カラオケ** | 夜景霓虹「焼肉」「カラオケ」 | 歌舞伎町一带 |

**地标**：新宿駅看板、都庁、歌舞伎町招牌、窄巷木立面（横丁意象）。

| 景别 | 画面要点 |
|------|----------|
| day_wide | 站前广场 + 拉面/牛丼店队列 + 远景都厅 |
| night_wide | 歌舞伎町霓虹 + 横丁灯笼烟 + 居酒屋暖光 |
| standard | 焼き鳥串 + ビール，背景灯笼巷 |

**招牌示例**：新宿駅、思い出横丁、ラーメン、焼き鳥、居酒屋、牛丼、カラオケ

**禁忌**：单一郊区校园、海南骑楼。

**已定稿**：`tokyo_shinjuku_day_wide.png` · `tokyo_shinjuku_night_wide.png` · `tokyo_shinjuku_day_standard.png`

| night_wide | 灯笼街、鳗鱼店暖光 |
| standard | 人形焼或天ぷら特写，雷門一角 |

|------|----------|
| **寿司** | カウンター握寿司、ネタ陈列 |

| **玉子焼き** | 玉子烧切块、长方块煎蛋 |
| 刺身 / 牡蠣 | 外食摊、冰鲜展示 |

**地标**：市场拱顶、鲜鱼箱、清晨繁忙。**禁**海南海鲜中文主招牌。

## 全城食客动线

1. **晨**：筑地 **海鮮丼·玉子焼き** → 浅草 **人形焼**  
2. **午**：上野 **弁当·阿美横** → 秋叶原 **カレー**  
3. **傍晚**：原宿 **クレープ** → 涩谷 **肉巻き**  
4. **夜**：新宿 **横丁焼き鳥** → 池袋 **豚骨拉面·饺子** → 大久保 **学生街拉面**

---

## 通用禁忌

- 巨型美食海报风、空街无饮食  
- 中国骑楼、海南中文小吃招牌  
- 全东京画成同一地标（须体现 **9 区差异**）  
- 电子学校画成郊区单一城堡校门
