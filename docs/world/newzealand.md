# 新西兰美食 · Aotearoa

## 概览

新西兰（**Aotearoa**）饮食由 **毛利（Māori）传统** 与 **19 世纪起英式移民** 叠加，再融入 **太平洋岛民、亚洲移民** 风味。南北岛物产差异大：北岛 **地热、库马拉（kūmara）、羊肉**；南岛 **绿唇贻贝、布拉夫生蚝、鹿肉**；西海岸 **银鱼（whitebait）** 季节性强。国民记忆常是 **炸鱼薯条、肉派、烧烤、Hokey Pokey 冰淇淋、帕芙洛娃（pavlova）**；节庆与团聚则离不开 **地炉 hāngī**。

**味型关键词**：lamb、seafood、kūmara、hokey pokey、manuka honey、feijoa、kiwifruit、tomato sauce、malt vinegar。

**资源状态（2026-05）**：海报 **1 品**（**Hāngī 地炉** ✅）；zine **1 品**（**Hāngī p01–p06** ✅）；街景 **待扩**（本土场景）。南极 **天堂湾** → [antarctica.md](antarctica.md)。

> 竖牌规划：**新西兰味道** / **Aotearoa Flavor** / 区域（**奥克兰味道** · **惠灵顿味道** · **罗托鲁瓦味道**）— 海报不绑定街景分区，见 [food-poster-diorama.md](../style/food-poster-diorama.md)。

## 毛利传统 · Māori kai

| 名称 | 特点 | 怎么吃 | 建议 slug |
|------|------|--------|-----------|
| **地炉 hāngī** | 热石埋坑（umu）慢烤；羊肉、猪肉、鸡肉、海鲜与根茎蔬菜 | 节庆、婚礼、marae 团聚；罗托鲁瓦常作文化体验 | `hangi` |
| **库马拉 kūmara** | 毛利带入的甘薯品种；紫/橙/白 flesh | 地炉同烤；现代常 **kūmara 薯条** | `kumara` / `kumara_chips` |
| **雷文阿面包 rēwena parāoa** | 以 **土豆「bug」发酵** 的毛利酸种面包 | 配黄油、汤或 hāngī 肉汁 | `rewena_pararoa` |
| **普哈 pūhā** | 本土绿菜，常与 **猪骨/猪肉** 同煮 | hāngī 或 boil-up 类锅物 | `puha` |
| **Boil-up** | 猪骨/香肠与 kūmara、土豆、pūhā 同锅 | 家常一锅端 | `boil_up` |
| **凯莫纳 kaimoana** | 海鲜总称：青口、鲍鱼、鱼、龙虾等 | 烧烤、hāngī 上层、炸 fritter | `kaimoana` |
| **帕乌阿 pāua** | 本土鲍鱼；壳作装饰，肉可 **fritter** 或奶油炖 | 西海岸、凯库拉一带名物 | `paua` / `paua_fritter` |
| **毛利炸面包** | 简单面团油炸 | 市集、 side | `maori_fried_bread` |

## 一日动线（规划）

1. **晨**：flat white + **meat pie** 或 sausage roll（bakery）。  
2. **午**：**fish & chips** 配 L&P，kūmara chips side。  
3. **下午**：**Hokey Pokey** 或 Whittaker's；feijoa 季试鲜。  
4. **夜**：**hāngī** 体验（罗托鲁瓦）或 **NZ lamb** BBQ；**pavlova** 收尾。
