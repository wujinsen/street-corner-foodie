## 日月湾 · `riyue_bay`

### 区位

**万宁市·日月湾** — 海南东海岸著名 **冲浪湾**；半月形海湾 + 椰林滨海公路 + 冲浪俱乐部。

| 项 | 说明 |
|----|------|
| 主景 | 半月海湾、浪线、椰林、冲浪者 |
| 气质 | 活力滨海 + 冲浪文化；**非**骑楼商埠、**非**三亚凤凰岛天际线主调 |
| 语言 | 中文店招（日月湾、清补凉、后安粉、海鲜烧烤） |

### 当地美食（生成须突出）

| 美食 | 街景表现 |
|------|----------|
| **清补凉** | 冰柜、椰奶配料、「清补凉」灯牌 |
| **椰子** | 椰子堆、鲜榨椰子摊 |
| **海鲜烧烤** | 炭烤烟雾、「海鲜烧烤」招牌 |
| **后安粉** | 「后安粉」小摊（万宁名物） |
| **冲浪小食** | 海滩咖啡/简餐、冲浪俱乐部窗口 |

### 三景别要点

| 景别 | 画面要点 |
|------|----------|
| day_wide | 日月湾海面 + 椰林公路 + 冲浪者 + 清补凉/烧烤摊 + Q 版游客 |
| night_wide | 湾面夜灯、烧烤摊暖光、椰林剪影（待扩） |
| day_standard | 前景清补凉或椰子，背景海湾一角（待扩） |

### 招牌示例

日月湾、冲浪、清补凉、后安粉、海鲜烧烤、椰子

### 禁忌

- 无饮食的空海滩明信片  
- 海报风巨型海鲜占满画面  
- 海口骑楼、石家庄面食、东京霓虹主调
