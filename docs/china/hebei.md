# 河北美食

## 概览

河北省饮食以**冀菜**为主，咸香扎实、面食与熏卤见长。省会**石家庄**（庄里）及正定、深泽、藁城、无极等县市名吃集中，详见 **[shijiazhuang.md](shijiazhuang.md)**。

**味型关键词**：咸香、酥香、面劲道、重油重辣、卤味浓。
