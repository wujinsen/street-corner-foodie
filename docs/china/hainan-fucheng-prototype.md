# 海口府城镇 · 街景原型

## 区位

**海口市琼山区府城镇** — 千年府城旧址；街景 = **古迹 + 老海口市井正餐/夜宵**（见 [hainan.md §老海口风味图鉴](hainan.md#老海口风味图鉴)）。

| 地标 | 说明 |
|------|------|
| **琼台书院 · 奎星楼** | 绿瓦红廊白墙 |
| **鼓楼 / 东门** | 古城意象 |
| **青石巷** | 鼓楼街、东门里等 |

## 当地美食（生成须突出）

摘自 `hainan.md` **老海口风味图鉴**，府城画面以**简餐 + 鱼煲 + 砂锅粥**为主线，**不出现琼山猪血汤**。

| 美食 | 要点 | 街景表现 |
|------|------|----------|
| **牛腩饭 / 猪脚饭** | 傍晚简餐主流，卤汁盖饭 | **博爱南路**老店招牌「牛腩饭」「猪脚饭」、大碗盖饭、卤汁色泽 |
| **海口鱼煲** | 砂锅鲜鱼配豆腐、粉条、时蔬，香辣或清淡因店而异 | **玉龙路**风格鱼煲砂锅、蒸汽、鱼块豆腐；招牌「海口鱼煲」「鱼煲」 |
| **鸽子粥 / 蟹粥** | 砂锅慢火，米开花绵密；生滚乳鸽或本地青蟹 | **新华南路**夜宵砂锅粥灯牌、白粥蒸汽、深夜围坐 |
| **海南粉** | 海口代表粉，可作邻摊点缀 | 小摊卤汁粉碗，勿抢鱼煲/粥主景 |

**动线（文档原句）**：暮·**博爱南牛腩猪脚饭** → 夜·**玉龙路鱼煲**或新华南砂锅粥。府城 wide/standard 以以上三类为主，猪血汤属府城文献记载但**本系列街景不表现**。

## 画面气质

- **白天 wide**：古街 + **牛腩饭/猪脚饭**简餐摊，食客围坐矮桌，Q 版小人吃盖饭  
- **夜景 wide**：红灯笼古街 + **鱼煲砂锅**与**鸽子粥/蟹粥**夜宵摊并列，蒸汽与暖灯  
- **standard**：奎星楼前或巷口，前景**鱼煲砂锅**特写，侧桌可放牛腩饭碗  

## 招牌示例

琼台书院、府城、**牛腩饭**、**猪脚饭**、**海口鱼煲**、**鸽子粥**、**蟹粥**、博爱南老店、鼓楼街

## 禁忌

- 地名误写 **「福城」**（须 **「府城」**：府城镇、府城小吃街、海口府城等）  
- **琼山猪血汤**、猪血大碗、胡椒猪血汤招牌  
- 只拍空古街无饮食  
- 堆满清补凉、椰子鸡、糟粕醋（非本线主线）  
- 骑楼连廊一条街、日本街景
