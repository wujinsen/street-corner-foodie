# 西藏美食

## 概览

西藏饮食建立在 **高寒牧区** 与 **河谷农耕** 之上：**青稞** 为粮，**牦牛** 为肉，**酥油** 为脂，**盐** 与 **茶** 为日常。传统一日从 **酥油茶 + 糌粑** 开始；拉萨等城市有 **甜茶馆** 文化（甜茶、藏面、牛肉饼）。林芝低海拔引入 **石锅鸡、菌菇**；日喀则、那曲以 **牦牛肉、风干肉、酸奶** 见长。口味总体 **咸香、奶脂、发酵微酸**，少辣（与川滇藏区交界带除外）。

**味型关键词**：青稞、酥油、牦牛肉、发酵酸奶、岩盐、甜茶、高原菌菇。

**资源状态（2026-05）**：**糌粑 · 酥油茶 · 甜茶 · 青稞酒** 海报 ✅；街景 **布达拉宫 night_wide** ✅；其余海报 / zine / 街景矩阵 **待扩**。

## 拉萨一日动线（食客向 · 规划）

1. **晨**：家庭或旅馆 **酥油茶 + 糌粑**。  
2. **午**：甜茶馆 **甜茶 + 藏面 + 牛肉饼**。  
3. **傍晚**： **风干牦牛肉** 或 **手抓牦牛肉** 小馆。  
4. **夜**（若林芝线）： **石锅鸡** 原汤。
