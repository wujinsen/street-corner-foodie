# 杭州街景 · 场景原型

> 画风 [street-view-diorama.md](../style/street-view-diorama.md)。入库 `asserts/Street View/cn/zhejiang/hangzhou/`。

## 命名

`cn_zhejiang_hangzhou_{slug}_{day|night}_{wide|standard}[_no_char].png`

## 1 · 西湖湖滨 `xihu`

| 项 | 内容 |
|----|------|
| 区位 | **西湖** 白堤/断桥一带湖滨步道、垂柳、游船 |
| 地标 | 断桥、保俶塔/雷峰塔远景、白墙黛瓦、石栏湖岸 |
| 美食 | **西湖醋鱼**（店招）、**龙井茶** 茶肆、藕粉、叫花鸡；茶点蒸笼 |
| 招牌 | 西湖、断桥、龙井茶、西湖醋鱼、杭州味道 |
| 气质 | 江南清丽、湖光；**非**热带骑楼、**非**北方夜市 |

| 画幅 | 文件名 |
|------|--------|
| day wide | `cn_zhejiang_hangzhou_xihu_day_wide.png` |
| night wide | `cn_zhejiang_hangzhou_xihu_night_wide.png` |
| day standard | `cn_zhejiang_hangzhou_xihu_day_standard.png` |

## 2 · 河坊街 `hefang`

| 项 | 内容 |
|----|------|
| 区位 | **河坊街** 仿古步行街、牌坊、灯笼铺 |
| 地标 | 河坊街牌坊、青砖木窗、吴山方向远景可选 |
| 美食 | **葱包烩**、**定胜糕**、**西湖藕粉**、吴山烤禽；摊档蒸汽 |
| 招牌 | 河坊街、葱包烩、定胜糕、藕粉 |
| 气质 | 市井烟火、宋韵商业街；**非**西安唐风主调 |

| 画幅 | 文件名 |

## 通用禁忌

- 空街无饮食、巨型单品海报风  
- 混用海南/东京主招牌  
- 画面过密（参考海口骑楼疏朗度）
