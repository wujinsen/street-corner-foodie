# 陕西美食

## 概览

陕西饮食以 **面食、牛羊肉、酸辣咸香** 见长；省会 **西安（古长安）** 为回民小吃与唐风夜市的代表城市。

**味型关键词**：酸辣、麻香、面劲道、孜然、羊肉本味。
