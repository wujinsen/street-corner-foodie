## 热带雨林风景区 · `rainforest`

### 区位

**五指山市·五指山热带雨林风景区** — 海南岛中部 **五指山** 五峰 + 原始热带雨林；景区栈道与黎苗风情小食。

| 项 | 说明 |
|----|------|
| **构图主语** | **风景区雨林 + 五峰山形**占画面 **>50%** |
| 主景 | 五峰剪影、雨林 canopy、雾谷、瀑布/溪流、木栈道 |
| 气质 |  humid 热带山岳 + 黎苗民俗点缀；**非**滨海、**非**骑楼 |
| 语言 | 中文店招（五指山、竹筒饭、山兰酒、清补凉） |

### 构图分层（`day_wide` · 有人物）

| 层 | 占比 | 内容 |
|----|------|------|
| **远景+中景** | **>50%（~55–60%）** | 五指山五峰 + 热带雨林 + 雾 + 瀑布/栈道 — **画面主体** |
| **近景** | **~40–45%** | **弱化**黎族风小食摊（竹筒饭/山兰酒/五色饭）+ **2～4 极小 Q 版游客** |
