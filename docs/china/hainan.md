# 海南美食

## 概览

海南省地处中国最南端，热带季风气候，物产以**海鲜、热带水果、椰子、香稻**为主。饮食整体偏**清淡、鲜甜、原味**，同时受东南亚与闽南影响，也有**酸、辣、糟醋**等鲜明口味。早茶「老爸茶」、大排档、椰子鸡火锅、各类粉面，以及海口常见的**牛腩饭**等盖饭简餐，**鱼煲**砂锅与各类**白粥、砂锅粥**夜宵，是日常与游客最常见的体验。若要按「纯血统老海口」理解本地味，可重点看下文 **[老海口风味图鉴](#老海口风味图鉴)**。

**味型关键词**：清甜、椰香、皮爽肉嫩、酸爽开胃、原汁原味、甜酸酱汁、胡椒浓汤。

---

## 老海口风味图鉴

按食客动线粗分：**早晨**（水巷口辣汤饭、府城猪血汤）→ **午间出城**（演丰咸水鸭、石山壅羊与黑豆腐）→ **傍晚老城**（博爱南牛腩猪脚饭、西门煎马鲛）→ **深夜街巷**（炸炸、新华南砂锅粥）。下列为文档其他章节未写透、或易被误认为「普通小吃」的海口本土代表。

### 市井深夜

| 名称 | 特点 | 地标/备注 |
|------|------|-----------|
| **海口炸炸** | 空心菜、金针菇、肉串等快炸，灵魂在**本地甜酸酱**或**咖喱酱**，甜酸与油脂并重；非普通炸串 | 义龙路、文明东、上坡路等老店；骑楼夜市亦常见 |
| **鸽子粥 / 蟹粥** | 砂锅慢火，米开花、粥绵密；生滚乳鸽或本地青蟹，清甜暖胃 | **新华南路**一带老字号，深夜热气最盛 |
| **琼山猪血汤** | 府城传统早点/下午茶；猪血嫩滑如豆腐，配大量韭菜、酸菜、猪大肠，汤头**酸咸、胡椒浓** | 常与**海南粉**同桌，解腻提神 |

### 走出市区的硬核正餐

| 名称 | 特点 | 地标/备注 |
|------|------|-----------|
| **演丰咸水鸭** | 美兰演丰，红树林咸淡水放养，食小鱼小虾与红树林籽；肉质紧实、皮薄脂少，**白切**即鲜咸无腥 | 与圈养鸭差异明显，出城午餐代表 |
| **石山壅羊** | 秀英石山火山岩区放牧，食当地草木（如「熟煮」），**膻味轻** | 与白切、清汤、火锅均可 |
| **石山黑豆腐** | 火山富硒黑豆 + 当地矿泉水、石磨；小铁锅煎至两面金黄，外酥里嫩、豆香浓 | 与壅羊并称石山「风味双璧」 |
| **煎海口马鲛鱼** | 琼州海峡鲜马鲛切厚片，少盐香煎至金黄，蒜瓣状鱼肉肥美紧致 | **西门**等大排档、家宴压轴；朴素吃法见「鲜」 |

### 本土粉类与其它

| 名称 | 特点 | 地标/备注 |
|------|------|-----------|
| **长流酸粉** | 秀英长流，粉条**偏厚偏宽**、凉拌；米醋、蒜头油、花生、牛肉干、本地酸菜，酸甜冰爽 | 与海南粉、甲子粉不同，夏日消暑 |
| **甲子粉** | 琼山甲子镇，粉条略粗、**韧滑**；分**甲子腌粉**（卤汁干拌）与**粑条汤**；配料多元（牛肉干、炸酥、花生、酸菜等） | 与海南粉、长流酸粉各成体系 |
| **辣汤饭** | 水巷口一带传统早餐，辣汤（常配猪杂、猪血等）浇饭或配米饭 | **水巷口**早市记忆 |
| **牛腩饭 / 猪脚饭** | 傍晚简餐主流，卤汁盖饭 | **博爱南路**老店聚集 |
| **玉龙路鱼煲** | 海口鱼煲老店聚集带，砂锅鲜鱼配豆腐、粉条、时蔬，香辣或清淡因店而异 | **玉龙路**夜宵觅食代表路段 |

> **一日拼图（速览）**：晨·水巷口辣汤饭 → 午·演丰咸水鸭 / 石山黑豆腐 → 暮·博爱南牛腩猪脚饭 → 夜·**玉龙路鱼煲**或西门煎马鲛、炸炸、新华南砂锅粥。全岛名菜（四大名菜、椰子鸡等）见下文各节。

## 饮食小贴士

1. **椰子鸡**：宜选用嫩椰青，现开现倒汤更清甜；鸡肉多选文昌鸡或类似走地鸡。  
2. **白切类**（鸡、鸭）：蘸料以姜葱油、青桔酱油、蒜蓉辣椒酱为主，突出本味。  
3. **酸粉类**：酸辣重口，怕辣可少放黄灯笼辣椒。  
4. **牛腩饭 / 猪脚饭 / 卤肉饭**：宜选炖卤至软烂、汤汁入味；多配酸菜或小菜解腻。  
5. **马鲛鱼丸汤**：铺前马鲛所制鱼丸鲜味足，汤宜清煮少调味。  
6. **清补凉**：冰饮版解暑，冬季也有热糖水版本。  
7. **海口鱼煲**：宜选活鱼现煲；豆腐、粉条吸汁，宜趁热；怕辣可先问清汤底辣度；老店可沿**玉龙路**一带寻觅。  
8. **砂锅粥 / 生滚粥**：砂锅粥多现点现煲，等候时间较长属正常；**鸽子粥、蟹粥**以新华南老店为参考；生滚粥宜滚熟即食。  
9. **炸炸**：酱汁是灵魂，甜酸与咖喱因店而异，宜趁热。  
10. **琼山猪血汤**：胡椒重、酸咸开胃，宜与海南粉搭配；猪血以嫩滑为佳。  
11. **演丰咸水鸭 / 石山壅羊**：出城品鲜，白切最能体现本味；黑豆腐宜现煎现吃。  
12. **长流酸粉 / 甲子粉**：长流偏凉拌酸甜；甲子偏韧滑，分腌粉与粑条汤，勿与海南粉、陵水酸粉混为一谈。  
13. **海鲜**：宜选活鲜，清蒸白灼最能体现鲜度；马鲛亦可试海口式厚片香煎。

## 街景如何使用

### 1. 按用途选文件

| 用途 | 推荐 |
|------|------|
| 公众号/网站横幅头图 | `*_wide.png`（21:9） |
| 方形封面、头像区、卡片 | `*_standard.png`（1:1） |
| PPT/网页背景、后期自己加字和人 | `*_no_char.png` |
| 需要生活感、故事感 | 不带 `_no_char` 的定稿（有 Q 版小人） |
| 海南专题主视觉 | `haikou_qilou_day_wide.png` 或 `haikou_bay_sunset_wide.png` |

### 2. 在 Markdown 里引用

```markdown
![海口骑楼老街](../asserts/Street%20View/cn/hainan/haikou/haikou_qilou_day_wide.png)
```

路径含空格时 URL 编码为 `%20`，或在 Obsidian / VS Code 中直接拖入文件自动生成链接。

### 3. 在网页 / 小程序里引用

```html
<img src="/asserts/Street View/cn/hainan/haikou/haikou_qilou_day_wide.png" alt="海口骑楼老街" />
```

部署时把 `asserts/Street View/` 拷到静态资源目录即可；文件名保持英文，避免中文路径。

### 4. 继续生成同风格新图

见 [street-view-diorama.md §Cursor 对话模板](../style/street-view-diorama.md#cursor-对话模板无需写具体文件名)。**无需**写「参考 haikou_qilou_day_wide.png」。

生成后若文件在 Cursor 的 `assets/`，需 **手动复制** 到 `asserts/Street View/` 才算入库。

### 5. 与其它两类搭配（不混风格）

| 类型 | 目录 | 用途 |
|------|------|------|
| 街景 | `Street View/` | 头图、地域氛围 |
| 海报 | `Gourmet recipe2/` | 菜品主视觉 |
| mini zine | `mini-zine/` | 故事页、做法页 |

详见 [ASSETS.md](../ASSETS.md#一篇内容怎么搭配示例)。
