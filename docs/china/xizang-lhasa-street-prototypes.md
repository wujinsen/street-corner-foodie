## 布达拉宫广场 · `potala`

### 地标

| 地标 | 说明 |
|------|------|
| **布达拉宫** | 红白宫墙依山而立，金顶在夜景中暖光勾勒 |
| **布达拉宫广场** | 开阔石板广场，可远观宫墙 |
| **药王山视角意象** | 远景可略见宫体层次，前景以广场市井为主 |

### 画面气质

- **night wide**：深蓝高原夜空 + 布达拉宫暖金顶光；广场边缘 **酸奶/青稞饼/酥油茶** 小摊，红灯笼与暖黄灯；**Q 版 chibi** 食客围坐矮桌、朝圣者剪影与游客并存，密度高  
- **day wide**：高原日光、宫墙红白对比；同上美食摊  
- **standard**：广场前景酸奶碗 + 宫墙中景
