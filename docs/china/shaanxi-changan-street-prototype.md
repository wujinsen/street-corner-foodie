## 场景 `changan`（长安·回民街）

| 项 | 内容 |
|----|------|
| 区位 | 西安 **回民街** / **大唐不夜城** 一带（唐风牌楼 + 市井小吃）；夜景 wide 偏灯笼夜市，白天偏牌楼与摊档 |
| 地标 | 钟楼远景可选、唐代牌楼、红灯笼、青石街 |
| 美食 | **肉夹馍**、**羊肉串**、**羊肉泡馍**（店招）、**凉皮**、**柿子饼**、镜糕 |
| 招牌 | 回民街、长安、西安小吃、肉夹馍、泡馍 |
| 气质 | 西北夜色、灯笼暖光；**非**海南骑楼热带主调 |

## 2 · 唐朝长安·不夜城 `tang_changan`

### 史实速查（出图前必读）

| 维度 | 要点 | 街景怎么用 |
|------|------|------------|
| **格局** | 棋盘里坊；**朱雀大街**南北中轴；**东市**（近宫、奢侈品）与 **西市**（丝路「金市」、胡商云集）为两大商市 | 画面宜 **宽街纵深** + 远处 **阙/坊门/塔影**，勿窄巷小家子气 |
| **规模** | 盛唐都城约 80+ km²，人口近百万；白居易「十二街如种菜畦」 | 建筑 **多层铺面连绵**、旗帜灯笼 **成列**，体现「百万人口之都」 |
| **胡风** | 西市胡商、**胡姬酒肆**（李白「落花踏尽…胡姬酒肆」）；胡饼、烤肉、葡萄酒、胡椒香料 | 胡姬酒旗、驼队意象（Q 版可）、胡汉服饰混搭的 chibi |
| **饮食** | **胡饼**（面脆油香）、**烤肉/烧烤**、**酪浆**、**汤饼**、**饆饠/毕罗**、葡萄酒、茱萸糕 | 多摊种 **同时入画**，各带小招牌，禁只画一种巨型食物 |
| **节俗灯火** | 唐代有 **宵禁、坊市定时**；上元等节庆与酒肆笙歌，后世文学与 **现代「大唐不夜城」** 取 **盛唐灯火繁华** 意象 | 夜景 = **浪漫不夜城**（千灯、乐舞、酒肆），**非**现代 LED 霓虹；doc 不当作 24h 无宵禁史实 |

| 项 | 要求 |
|----|------|
| **视角** | **高角度俯视 / 航拍式** 等距微缩；一眼见长安城片，非街口贴脸 |
| **格局** | 棋盘 **里坊**、**朱雀大街** 中轴纵贯、**东市/西市** 方块可辨 |
| **远景** | 城墙轮廓、宫阙屋脊、**大雁塔** 剪影占天际线 |
| **灯火** | 坊市与御街灯笼如 **星点**，疏朗不糊 |
| **美食** | **西市** 片区可见小摊灯火、炊烟/蒸汽（胡饼、酒肆），不必近景巨型食物 |
| **人物** | 可选 **极少** 微小人影；优先城市尺度 |

### 画面分层（街口近景 · 备用）

> **禁**：满屏堆摊、挤满 chibi、招牌糊成一团。大气靠 **纵深 + 留白 + 主建筑**，不靠密度。

| 层 | 内容 |
|----|------|
| **远景** | 佛塔/宫阙剪影、疏朗星空；占画面上方 **1/3** |
| **中景** | **宽阔御街**（青石可见、街面留白约 30%）、一座主牌楼或胡姬酒肆 |
| **近景** | 左右各 **1～2** 层酒楼即可；灯笼 **成列但间距大** |
| **美食** | **2～3 处**可读摊档（如胡饼炉 + 烤肉架 + 酒肆门前酪浆），其余暗示即可 |
| **人物** | **≤6** 个小号 chibi，散在街中远景，不挡主建筑 |

| 项 | 内容 |
|----|------|
| 区位 | **盛唐长安不夜城**意象：朱雀大街灯火 + 西市胡风酒肆（宽街纵深感） |
| 地标 | 阙、坊墙、飞檐酒楼、远端塔影；**无**现代钟楼、玻璃幕墙、英文霓虹 |
| 美食 | 见上表；招牌可加 **不夜城**、**长安**、**西市**、**胡姬酒肆**、**胡饼** |
| 气质 | **大气蓬勃**、灯火万家；**非**现代回民街肉夹馍主招牌 |
