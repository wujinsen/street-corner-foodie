# 新疆美食

## 概览

新疆饮食以 **清真与多民族** 为底色：**维吾尔、哈萨克、汉、回** 等风味并存。地理上 **北疆** 偏农耕与汉餐融合，**南疆** 以 **喀什、和田** 为代表的 **馕、抓饭、烤肉** 更集中；**伊犁** 有 **熏马肠、马肉** 等哈萨克传统。

主食 **小麦面**（拉条子、拌面、馕）与 **大米**（抓饭）并重；蛋白以 **羊肉、牛肉** 为主，调味离不开 **孜然、辣椒、洋葱、番茄**。口味 **咸香、香料浓郁、油脂饱满**；夜市与巴扎是食客动线核心。

**味型关键词**：孜然、辣椒、洋葱、番茄、馕坑、抓饭、拉条子、酸奶、甜咸并置（部分点心）。

## 食客动线（规划 · 喀什 + 乌鲁木齐）

1. **早**：馕 + 奶茶或牛肉面。  
2. **午**：抓饭或过油肉拌面。  
3. **晚**：大盘鸡 / 馕坑肉 + 皮辣红 + 烤包子。  
4. **夜**：巴扎羊肉串、玛仁糖、卡瓦斯。
