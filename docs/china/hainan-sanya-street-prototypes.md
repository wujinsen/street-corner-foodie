## 三亚湾 · `sanyawan`

### 区位

**三亚市·三亚湾路 / 椰梦长廊（Coconut Dream Corridor）** — **三亚湾** 海面为画面主语；前景仅留滨海步道与小摊。

| 项 | 说明 |
|----|------|
| **构图主语** | **三亚湾海面**占画面 **~50%**（对齐 `haikou_wanlv_night_wide` 景深） |
| 视角 | **偏高俯视** 等距微缩；三层：椰梦长廊 → 湾面 → 凤凰岛/天际线 |
| 地标 | 宽阔海湾、椰林滨海道；远景 **凤凰岛** 帆形建筑、三亚市区灯带 |
| 气质 | 热带滨海夜景 + 蓝白城市反光 + 椰林暖灯；**非**大排档占满前景 |
| 语言 | 中文店招（海鲜大排档、清补凉、椰子） |

### 构图分层（night_wide · 必遵）

| 层 | 占比 | 内容 |
|----|------|------|
| **前景** | ~15% | 椰梦长廊窄步道、椰子树、小海鲜/清补凉摊、Q 版游客 |
| **中景（主）** | **~50%** | **三亚湾** 宽阔海面、倒影、小渔船/游艇 |
| **远景** | ~25% | 凤凰岛 + 三亚天际线（蓝白 LED）、薄雾、深蓝天 |

### 当地美食（生成须突出）

| 美食 | 街景表现 |
|------|----------|
| **海鲜大排档** | 小摊蒸汽、贝类/虾、霓虹「海鲜大排档」 |
| **清补凉** | 冰柜、椰奶配料、「清补凉」灯牌 |
| **椰子 / 烧烤** | 椰子堆、炭烤海鲜烟雾 |
| **糟粕醋**（可选小招牌） | 「糟粕醋」小灯牌，勿抢湾面主景 |

### 三景别要点

| 景别 | 画面要点 |
|------|----------|
| night_wide | **三亚湾占半幅** + 椰梦长廊 + 凤凰岛远景 + 小摊/chibi |
| day_wide | 椰林 + 湾面 + 海鲜摊 |
| day_standard | 前景清补凉或椰子，背景海湾一角 |

### 招牌示例

三亚湾、椰梦长廊、海鲜大排档、清补凉、椰子、凤凰岛

### 禁忌

- 无饮食的空海滩明信片  
- **整排大排档占满前景**（海湾非主语）  
- 海报风巨型海鲜占满画面  
- 海口世纪大桥/骑楼/东京霓虹主调  

## 大东海 · `dadonghai`

### 区位

**三亚市·大东海旅游区** — **大东海** 月牙形海湾为画面主语；前景仅留沙滩步道与小摊。

| 项 | 说明 |
|----|------|
| **构图主语** | **大东海海面 + 月牙湾**占画面 **~50%**（对齐 `haikou_wanlv_night_wide` 景深） |
| 视角 | **偏高俯视** 等距微缩；三层：沙滩步道 → 湾面 → 鹿回头/酒店灯带 |
| 地标 | 月牙形白沙滩、椰林；远景 **鹿回头** 山廓、滨海酒店灯带 |
| 气质 | 热带度假海滩夜景 + 蓝绿海面反光 + 椰林暖灯；**非**大排档占满前景 |
| 语言 | 中文店招（海鲜烧烤、清补凉、大东海） |

### 构图分层（night_wide · 必遵）

| 层 | 占比 | 内容 |
|----|------|------|
| **前景** | ~15% | 大东海沙滩窄步道、椰树、小烧烤/清补凉摊、Q 版游客 |
| **中景（主）** | **~50%** | **大东海** 月牙海湾、蓝绿海水、倒影、近岸浪花 |
| **远景** | ~25% | 鹿回头山影 + 滨海酒店天际线、薄雾、深蓝天 |
