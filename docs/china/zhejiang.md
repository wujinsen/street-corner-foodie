# 浙江美食

## 概览

浙江省饮食偏 **鲜、嫩、滑**，杭帮菜尤重河鲜与时蔬，糖醋芡汁明亮不腻。西湖醋鱼为杭州代表名菜。

---

## 代表菜品

| 名菜 | 特点 | slug |
|------|------|------|
| **西湖醋鱼** | 草鱼（或桂鱼等）汆熟，浇糖醋芡，酸甜鲜嫩、醋香明显 | `xihu_cuyu` |
| **东坡肉** | 带皮五花肉方块，冰糖黄酒酱油慢炖，色如玛瑙、软烂不腻；杭州名肴 | `dongpo_rou` | ✅ p01–p06 · `song` · 3D chibi 全员女性 · 2026-05-19 六页重绘 |
| **葱油炒饭** | 葱油煸香、米粒分明，沪浙家常锅气 | `congyou_chaofan` |
| **东坡豆腐** | 东坡肉味型烧嫩豆腐，黄酒酱油冰糖焖至软嫩 | `dongpo_doufu` |
| **霉干菜炒饭** | 绍兴霉干菜、肉末炒饭，浓香锅气 | `meigan_cai_chaofan` |
| **蟹粉豆腐** | 蟹黄蟹肉烩嫩豆腐，金秋名物 | `xiefen_doufu` |
| **绍兴臭豆腐** | 苋菜梗发酵，蒸或炸，闻臭吃香 | `shaoxing_choudoufu` |
| **雪菜肉丝炒饭** | 雪里蕻、肉丝、笋丁炒饭，咸鲜锅气 | `xuecai_rousichao` |
