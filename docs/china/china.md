# 中国美食（全国层）

## 概览

中国饮食按 **八大菜系** 与南北物产分化；日常主食以 **米、面** 为主，爆炒、蒸煮、卤炖并重。省级代表菜见 [hainan.md](hainan.md)、[zhejiang.md](zhejiang.md)、[hebei.md](hebei.md) 等；本文收录 **跨省常见品类**（炒饭、豆腐等），供海报 / zine 选题与 slug 统一。

海报入库：**必须** `asserts/Gourmet recipe2/cn/{省}/`（与海南 `cn/hainan/`、河北 `cn/hebei/` 相同）；**禁止**在 `cn/` 根目录堆成品 PNG。菜品归属省见下表「主关联省」；**竖牌**用 **「{省}味道」**。

## 豆腐 · 图鉴（全国）

**共性**：大豆（或黑豆）点卤凝固；按凝固剂与压制分为 **嫩豆腐 / 南豆腐**、**北豆腐 / 老豆腐**、**内酯豆腐**；再加工有 **豆皮（千张）**、**腐竹**、**油豆腐（豆腐泡）**、**素鸡**、**冻豆腐** 等。吃法覆盖热炒、砂锅、凉拌、小吃、汤羹、火锅配菜。

**与项目已有条目**：海报已定稿 → **麻婆豆腐**（川）、**家常豆腐**（冀）；海南见 [石山黑豆腐](hainan.md#老海口风味图鉴)、[斋菜煲](hainan.md)、[海口鱼煲](hainan.md) 配豆腐。

### 原料与形态（选菜前先分清）

| 形态 | 别称 | 口感 | 常见用途 |
|------|------|------|----------|
| **嫩豆腐 / 南豆腐** | 石膏豆腐 | 软嫩易碎 | 麻婆豆腐、蟹粉豆腐、汤羹 |
| **北豆腐 / 老豆腐** | 盐卤豆腐、板豆腐 | 紧实耐煎 | 家常豆腐、红烧豆腐、炖锅 |
| **内酯豆腐** | 日本豆腐状 | 极嫩 | 凉拌、蒸蛋羹底 |
| **豆腐皮 / 千张** | 百叶 | 薄韧 | 卷菜、板面配菜、凉拌 |
