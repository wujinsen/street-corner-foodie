# 北京美食

## 概览

北京为六朝古都、元明清都城，饮食融合 **宫廷御膳、官府菜、清真风味与胡同市井**。近代名片是 **烤鸭、涮羊肉、炸酱面**；更早则有 **炙子烤肉、卤煮、炒肝、豆汁焦圈** 等「老北京」早点与夜宵。宴席名物 **满汉全席** 象征清代满汉合宴（今宴多为代表菜组合，非逐道还原一百零八品）。

**味型关键词**：咸鲜醇厚、酱香、酥烂、汤清、麻酱浓香、烤鸭皮脆、发酵酸香（豆汁）。

> 本土脉络见 **[京城风味图鉴](#京城风味图鉴)**；寻店见 **[寻味地标](#寻味地标)**。全国层炒饭、豆腐等见 [china.md](china.md)。

## 饮食小贴士

1. **烤鸭**：宜现烤现片；先卷饼蘸酱，鸭架可熬汤或椒盐。挂炉皮更脆，焖炉肉更嫩，因店而异。  
2. **涮羊肉**：清汤锅底先涮肉后菜；芝麻酱加韭菜花、腐乳、辣椒油按口味调。  
3. **炸酱面**：菜码宜多样清爽，拌匀趁面热；酱咸宜少放。  
4. **卤煮炒肝**：重口荤腥，不喜内脏慎点；炒肝要蒜香浓、芡厚而不泄。  
5. **豆汁**：发酵酸味，初尝可点小碗配焦圈；本地人佐咸菜。  
6. **豆汁 vs 酸梅汤**：前者早点，后者配烧烤解腻。  
7. **簋街小龙虾**：季节性强，夏夜排队常见；辣度可先问清。  
8. **海报 / zine**：竖牌 **北京味道**；宫廷菜、烤鸭多 **`qing`** 强锚定；炸酱面、卤煮可 `republic`·`contemporary`；见 [mini-zine-dynasty-chibi.md](../style/mini-zine-dynasty-chibi.md)。
