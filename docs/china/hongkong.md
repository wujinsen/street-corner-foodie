# 香港美食

## 概览

香港饮食以 **广府粤菜** 为底，叠加 **英式殖民时期** 与 **东南亚移民** 影响，形成独特 **港式** 体系：**点心** 早茶、**烧腊** 斩件、**云吞面** 竹升面、**茶餐厅** 奶茶与常餐、**大排档/车仔面** 街头小食。味型 **清鲜、镬气、甜咸并置**； sauce 常用 **蚝油、柱侯、XO**。

**味型关键词**：镬气、烧味、丝袜奶茶、蛋香、咖喱鱼蛋、避风塘、虾膏。

**资源状态（2026-05）**：**肠粉** 海报 ✅；其余专属目录 `cn/hongkong/` **待扩**。部分 **粤港共有** 菜（如咸鱼鸡粒炒饭）已定稿在 `cn/guangdong/`，见下表交叉引用。

## 香港一日动线（食客向 · 规划）

1. **晨**：茶楼 **虾饺 + 烧卖 + 肠粉 + 普洱**。  
2. **午**： **云吞面** 或 **烧腊双拼饭**。  
3. **下午**： **丝袜奶茶 + 菠萝油** 或 **蛋挞**。  
4. **夜**： **避风塘炒蟹** / **打边炉**；旺角 **咖喱鱼蛋 + 鸡蛋仔**。

竖牌：**香港味道** / **港岛味道** / **九龙味道**（海报不绑定街景分区）。
