# 石家庄美食

## 概览

石家庄为河北省会，地处华北平原，历史上为「南北通衢、燕晋咽喉」。饮食承**冀菜**与中原、山西风味，整体偏**咸香、扎实、重面食**；虽名「安徽牛肉板面」，其**发扬光大与精神故乡在石家庄**。街头以板面、**缸炉烧饼**撑起日常，宴席与老字号多见扒鸡、卤味；**正定古城**承载半数底蕴，深泽、无极、藁城、栾城、辛集等县市各有「隐藏高手」。

**味型关键词**：咸香、酥香、面劲道、重油重辣、卤味浓、蒸碗肥而不腻。

> 正定、藁城、无极、深泽等现属石家庄市辖区或辖县。庄里本土脉络见 **[庄里风味图鉴](#庄里风味图鉴)**；寻店见 **[寻味地标](#寻味地标)**。

## 庄里风味图鉴

### 撑起庄里半边天的面食

| 名称 | 特点 | 备注 |
|------|------|------|
| **正宗安徽牛肉板面** | 宽而有嚼劲的手工面；灵魂是**黑红发亮、重油重辣**的牛油卤汁；标配**卤蛋、豆皮、大红肠（或亲亲肠）**，再嚼几颗炸得干香的**魔鬼干辣椒** | 虽名安徽，**庄里才是市面**；深夜、宿醉后的终极救赎 |
| **缸炉烧饼** | 倒扣瓷缸贴壁烘烤，**方形**、芝麻密布；外皮酥到掉渣，内里分层，面香、芝麻香、椒盐微咸 | 神吃：夹**深泽肉糕**或驴肉，热烧饼化开肉脂 |
| **无极饸饹** | 无极县招牌，荞麦面经**饸饹床**压入沸水；条圆筋道，牛羊骨浓汤，出锅浇**红油、蒜泥、香菜** | 大口嗦，极其过瘾 |
| **藁城宫面** | 手工拉制**细如发丝**的空心面，慈禧贡品；煮而不烂，汤多清淡鲜美（番茄鸡蛋、肉丝等），吃面丝滑微咸 | 读作 **gǎo** |

### 正定古城：硬核肉食传承

石家庄美食约一半底蕴在**正定**：

| 名称 | 特点 | 备注 |
|------|------|------|
| **正定八大碗** | 传统宴席蒸碗，多**四荤四素**（扣肉、条子肉、丸子、焖子等）；码味久蒸，肥而不腻、入口即化 | 配米饭或刚出炉馒头 |
| **金凤扒鸡** | 庄里家喻户晓中华老字号；**循环老卤**焖制，五香脱骨，鸡皮金黄、肉质酥烂 | 市区与正定均可遇 |
| **正定马家卤鸡** | 江北著名**清真卤鸡**，历史更久；型美肉嫩、清香不腻 | 国家地理标志产品 |
| **正定热切丸子** | 非南方鲜肉丸：猪肉、红薯淀粉、香料拌馅，荷叶或布包**蒸熟**；放凉切片，蘸蒜酱，弹牙鲜香 | 正定独有口感 |

### 各县市隐藏民间高手

| 名称 | 特点 | 备注 |
|------|------|------|
| **深泽肉糕**（西河肉糕） | 猪肉、猪皮、骨汤加**绿豆淀粉**与香料熬糊冷凝；热食切片，半透明、滑溜细腻 | 外地极罕见；夹热缸炉烧饼为绝配 |
| **因村驴肉** | 栾城因村，老汤酱制，肉质红润、咸香透味 | 庄里人爱切大盘驴肉、驴肠、驴焖子佐酒 |
| **辛集咸驴肉** | 辛集腌制，咸香耐存 | 与因村、火烧并列为庄里驴肉文化 |

## 饮食小贴士

1. **牛肉板面**：庄里灵魂在**牛油辣卤**与配菜；卤蛋、豆皮、肠、炸干辣椒宜加满；辣度因店而异，可先点小碗。  
2. **缸炉烧饼**：宜现烤现吃；**夹热深泽肉糕**或驴肉为本地吃法；亦可配羊杂汤、罩火烧。  
3. **无极饸饹**：重红油蒜泥，宜趁热大口嗦；与市区普通饸饹面店可区分产地。  
4. **藁城宫面**：忌久煮糊汤，清淡汤头更能衬出细丝空心口感。  
5. **扒鸡 / 卤鸡**：金凤偏五香酥烂，马家偏清香不腻；正定古城宜尝马家卤鸡。  
6. **八大碗 / 热切丸子**：八大碗多为套餐或预定，直奔正定老街；热切丸子宜凉切蘸蒜酱。  
7. **深泽肉糕**：须**热食**夹热烧饼，冷吃口感差；外地少见，可在庄里特产店试。  
8. **驴肉**：因村、辛集偏酱咸大盘吃；火烧宜热饼夹温肉。  
9. **金毛狮子鱼**：宴席菜，需提前预订或选做冀菜的餐馆。

## 命名规范

总规范见 [ASSETS.md §地区层级](../ASSETS.md#地区层级与文件命名)。本文为 **市级文档**（`province: 河北`），街景文件名保留全 geo。

```
路径：海报·zine → Gourmet recipe2/cn/hebei/、mini-zine/cn/hebei/
      街景 → Street View/cn/hebei/shijiazhuang/
文件名：海报·zine → {slug}_poster.png / {slug}_*_mini_zine*.png（路径已含 cn/hebei，不必再写 cn_hebei_）
      街景 → cn_hebei_shijiazhuang_{场景}_{day|night}_{wide|standard}[_no_char].png
```

| 字段 | 含义 |
|------|------|
| `slug` | 拼音菜名，如 `bannianmian`、`ganglu_shaobing` |
| `geo_prefix` | 文档清单用 `cn_hebei_`；街景成品文件名须带 `cn_hebei_shijiazhuang_` |
