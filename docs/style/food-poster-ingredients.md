## 按菜定布局 · 人料皆可变（2026-05 · 新旧对话必守）

| 维度 | 规则 |
|------|------|
| **人物** | **按菜变**：3D chibi · **默认全员女性** · 人数 **3～5** 查本菜「有人物」表（清补凉 5、后安粉 3…）· 桌边/四角 · **不进主菜/锅** · 对白体 ≤ 人数 |
| **食材展示** | **按菜变**：料名、件数 **4～6**、器皿形态、摆放均查本菜底行表 — **不**全系列统一 5 人 + 6 同款碗 |
| **同 slug 锁定** | `_poster` + `_poster_no_char`：**同时代、同布景、同人数、同料名与器皿** |
| **木牌** | 样式统一（**横放**、木纹、禁绿矩形）；**料名与件数随菜**；**boluo 清新风**亦 **必横木牌**（见 [food-poster-diorama.md §boluo](food-poster-diorama.md#boluo-清新风--清晰风2026-05-19--新旧对话必守)） |

## 无人物版 · 底部重点食材展示（按菜）

底部展示**本菜识别度最高的配料/蘸料**：常见为 **横排小碟/小碗** + **横放木牌**（碗/碟正下方或碗前桌面），**不是**固定六只同款碗、**不是**与主菜无关的凑数料。

**器皿可按菜替换**（示例）：

| 食材类型 | 推荐容器 |
|----------|----------|
| 米粒、切丁、粉末 | 青花瓷小碗、白瓷碟 |
| 液体（酱油、黄酒、卤汁） | 小陶壶、酱油碟、勺舀 |
| 整块（火腿、豆腐、鱼） | 竹匾、木板、长碟 |
| 香料（姜、葱、花椒） | 浅碟、石臼旁小碟 |

### 料签 · 木牌（2026 起统一，替代绿底矩形）

| 项 | 要求 |
|----|------|
| 形态 | **横长方形小木牌**，**平放、居中置于每只料器皿正下方**（首选，与蟹粉豆腐/叉烧炒饭底行同款）；竖牌立于碗侧仅旧稿保留 |
| 器皿 | **按食材选**碗/碟/壶/木盘等，**不必**全图同款青花瓷小碗（见 §原则 · 器皿） |
| 材质感 | 浅黄褐 **木纹**、略旧；**深褐细边框**；四角可有传统 **缺口/装饰** |

| 规则 | 说明 |
|------|------|
| **数量** | 通常 **4～6 件**；料少 4、料多 5～6。**不必凑满 6**，禁止为凑数加无关料。 |
| **器皿** | **按本菜食材选**碗/碟/壶/板，不必同款；有人物版与无人物版 **同料名、同件数**。 |
| **选料** | 只列本菜 **重点食材**；件数 4～6 **按表**，不凑满 6。 |
| **禁止** | 全库统一「六同款碗 + 五人」模板；为凑数加无关料。 |
| **标签** | 木牌横放器皿下，中文 2～4 字。 |
| **生成前** | 时代表 + `| 厨师人数 |` + `| 料名 | 容器 | 件数 |` 再写 prompt。 |

## 写入 prompt 的格式（底行料碗 · 中英文）

**中文要点**：主菜 **CENTER-UPPER 不遮挡**；底行最底 **12～18%** 放 {N} 件料（器皿随菜），每件 **横放木牌** 在器皿正下方或碗前桌面（浅黄褐木纹、深褐框、黑字横排 2～4 字）。**禁止**绿底矩形。

```text
CRITICAL COMPOSITION: hero dish CENTER-UPPER 45-55% fully visible NOT blocked. CLEAR GAP between dish bottom and ingredient props.
CRITICAL PLACEMENT (if characters): {CHEF_COUNT} cute female 3D chibi at FOUR OUTER CORNERS, smaller scale, NO overlap each other, NO clipping into dish, hands outside bowl/wok rim.
Bottom foreground only lowest 12-18%: {N} ingredient items in varied vessels ({VESSEL_LIST}). Each has horizontal rectangular wooden plaque flat UNDER or in front on table (tan wood grain, dark brown border, black horizontal brush Chinese 2-4 chars): {LABEL_1} {LABEL_2} ...
NOT green rectangular labels NOT digital UI stickers NOT six identical copy-paste bowls unless dish requires.
Do not add unrelated sides. Do not force exactly six items unless the dish needs six.
```

有人物版：模板见 [.cursor/skills/meishi-food-poster/prompt-templates.md](../../.cursor/skills/meishi-food-poster/prompt-templates.md) §A；无人物 §C。或写 `same bottom ingredient row and gap as no-char version`。

`{N}`、器皿、标签来自上表或省 md；**厨师人数与料件数分开定**。
