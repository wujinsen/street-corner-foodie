# Mini-Zine 地域维度（Regional Dimensions）

生成前先填表。**系列壳固定，下列四维按当地特色取值**——不要把某一省（如海南）的默认值套到全国或全球。

## 系列层（全球统一，不随地域改）

- 版式：故事四栏 + 做法四步 2×2；角标 `{地域标签}风味 mini zine 02|03`
- 四套产出：`story` / `recipe` × 标准 / `_no_char`
- 信息区：羊皮纸/卷轴质感面板
- 主图：写实食物摄影居中
- **禁止**：引用或模仿 `asserts/*_poster.png`（商业海报：霓虹、TOP1、底部食材阵列、3D 红标题等）

---

## 四维配置表（每道菜 / 每个地域填一行）

| 维度 | 填什么 | 原则 |
|------|--------|------|
| **1. 背景** | 地标、光线、季节气质 | 符合**当地 + 该菜常见场景**；水墨/柔光日间信息图风，与西湖样张同族 |
| **2. 标题与底栏** | 书法色、底栏色、文案 | 符合**当地色谱与饮食文化**；保留「大标题 + 副题/引言 + 底栏一句」结构 |
| **3. Q 版** | **时代** + **优先女性**（默认全员女性 chibi）+ 服饰、道具 | **3D chibi**；见 [mini-zine-dynasty-chibi.md](../../../docs/style/mini-zine-dynasty-chibi.md) §角色性别；无锚定可 **候选池随机** |
| **4. 禁止** | 除 poster 外的额外禁令 | 默认禁 poster；若某地夜市是**该菜真实吃法场景**可保留街边元素，但**不用海报构图** |

结构固定：`{菜名}故事与吃法` / `做法小志` + `四步做出{菜名}` + 底栏 `{地域标签} | {半句 slogan}`。

| 江南 | 青绿/黛绿毛笔 + 青绿底栏 | `江南风味 \| 共享一盘春天` | `鲜嫩酸甜 \| 杭帮经典` |

## 维度 4 · 禁止（全球）

**始终禁止**

- 复制 `asserts/*_poster.png` 的版式与元素
- 无 mini zine 结构的大字 3D 红标题、TOP1 勋章、底部六小碗海报阵列

**按地域判断（非一律禁止）**

- 夜市/串灯：仅当**该菜真实食用场景**且用户未要求「日间系列统一」时，可局部出现；仍保持 zine 四栏/四步结构
- 民族服饰：仅当菜品或文档明确关联时使用，不作所有海南菜的默认

## 工作流

1. 用户给出：**地域单元**（省 / 市 / 国）+ **菜名**
2. 查本表或新建一行配置 → 填入 `prompt-templates.md` 占位符
3. 锚图：`asserts/mini-zine/_templates/487c2f*.jpg` + `5bfa29c*.jpg` + 同地域目录内 `*_mini_zine.png`
4. 生成四套 → 写入 `asserts/mini-zine/{cc}/{admin}/`

## 文件命名（可选扩展）

`{slug}_story_eating_mini_zine.png`；若需区分城市：`slug` 含地域，如 `sanya_hele_xie`（三亚和乐蟹）。
